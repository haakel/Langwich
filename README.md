# Langwich

> تبدیل هوشمند چیدمان کیبورد فارسی ↔ انگلیسی برای ویندوز

متن اشتباه را انتخاب کنید، کلید میانبر را بفشارید — Langwich آن را در همان لحظه بین «انگلیسی تایپ‌شده با چیدمان فارسی» و «فارسی» تبدیل می‌کند. در **هر برنامه‌ای** کار می‌کند: مرورگر، Notepad، IDE، تلگرام و...

```
شما تایپ کردید:  sghl
بعد از Langwich: سلام
```

---

## ✨ امکانات

- 🔄 **تبدیل خودکار تشخیص جهت** — متن فارسی → انگلیسی و بالعکس، بدون نیاز به انتخاب دستی
- ⌨️ **میانبر سراسری** — پیش‌فرض `F10`، قابل تغییر از تنظیمات
- 🌐 **تغییر خودکار زبان کیبورد** — بعد از تبدیل، زبان ویندوز هم هماهنگ می‌شود (قابل غیرفعال‌سازی)
- ⌨️ **پشتیبانی از کیبورد Persian Standard** — حرف «پ» روی کلید `\` (قابل تنظیم)
- 🎨 **تم تاریک/روشن**
- 🖥️ **اجرا در سینی سیستم** — بدون پنجره‌ی مزاحم، همیشه در دسترس
- 🚀 **سبک و سریع** — بدون وابستگی خارجی، بدون NuGet

## 📥 نصب

### روش ۱: نصب‌کننده (پیشنهادی)

از صفحه‌ی [Releases](https://github.com/haakel/Langwich/releases) فایل `Langwich-Setup-1.1.0.exe` را دانلود و اجرا کنید. نصب‌کننده کامل است — **نیازی به نصب .NET ندارد**.

### روش ۲: نسخه‌ی قابل‌حمل (Portable)

از Releases، فایل `Langwich.exe` را دانلود و مستقیم اجرا کنید. بدون نصب، بدون نیاز به .NET.

> 💡 نسخه‌ی `Langwich-Light.exe` برای سیستم‌هایی که .NET 10 Runtime دارند (حجم خیلی کم‌تر).

## 🚀 استفاده

| مرحله | کار |
|---|---|
| ۱ | متن اشتباه را در هر برنامه‌ای **انتخاب** کنید |
| ۲ | `F10` را بفشارید |
| ۳ | متن خودکار تبدیل می‌شود! |

### مثال‌ها

| متن اشتباه | بعد از تبدیل |
|---|---|
| `sghl` | `سلام` |
| `]d;i hvldk` | `چی خبر دارین` |
| `سلام` | `sghl` |
| `به` | `fi` |

### منوی سینی

روی آیکون Langwich در سینی سیستم (کنار ساعت) **راست‌کلیک** کنید:

- **⚙ تنظیمات** — پنجره‌ی تنظیمات
- **✕ خروج** — بستن برنامه

## ⚙ تنظیمات

| گزینه | توضیح |
|---|---|
| **میانبر سراسری** | کلید فعال‌سازی تبدیل (پیش‌فرض: F10) |
| **اجرای خودکار با ویندوز** | شروع Langwich هنگام ورود به ویندوز |
| **نمایش اعلان بعد از تبدیل** | اعلان کوچک بعد از هر تبدیل |
| **تغییر زبان کیبورد بعد از تبدیل** | هماهنگ‌سازی زبان ویندوز با متن تبدیل‌شده |
| **کیبورد Persian Standard** | اگر «پ» روی کلید `\` است (به‌جای `m`) |
| **تم تاریک** | تم تیره یا روشن |

## 🛠 ساخت از سورس

### پیش‌نیازها

- [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0) برای ویندوز
- Visual Studio 2022 (اختیاری — برای ویرایش راحت‌تر)

### بیلد

```bash
dotnet build Langwich.sln
```

### خروجی exe تک‌فایله (برای توزیع)

```bash
dotnet publish Langwich/Langwich.csproj \
  -c Release -r win-x64 \
  --self-contained true \
  -p:PublishSingleFile=true \
  -o ./publish
```

خروجی: `publish/Langwich.exe` — روی هر ویندوز x64 اجرا می‌شود.

## 🔧 مشکلات رایج

### F10 کار نمی‌کند

1. **میانبر توسط برنامه‌ی دیگری گرفته شده** → از تنظیمات یک کلید دیگر انتخاب کنید (مثلاً `Ctrl+F10`)
2. **برنامه‌ی هدف با دسترسی Administrator اجرا شده** → Langwich را هم به‌صورت Administrator اجرا کنید

### آیکون در سینی نیست

روی فلش ▲ کنار ساعت کلیک کنید و Langwich را پیدا کنید. (بعضی ویندوزها آیکون‌های سینی را مخفی می‌کنند.)

### SmartScreen / آنتی‌ویروس هشدار می‌دهد

این برای exe های امضا‌نشده طبیعی است (False Positive). روی **More info ← Run anyway** کلیک کنید. سورس کامل برنامه در همین ریپو قابل بررسی است.

## ⚠️ محدودیت‌های شناخته‌شده

- **بازی‌های تمام‌صفحه:** بیشتر بازی‌ها از کلیپ‌بورد استاندارد استفاده نمی‌کنند؛ تبدیل کار نخواهد کرد.
- **برنامه‌های Administrator:** اگر برنامه‌ی هدف با دسترسی Admin اجرا شده، Langwich هم باید Admin باشد.
