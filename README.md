## ⚡ Langwich چطور کار می‌کند؟

**مشکل:** گاهی متنی را با چیدمان فارسی تایپ می‌کنید ولی کیبورد روی انگلیسی بوده،
یا برعکس. مثلاً می‌خواستید بنویسید **«سلام»** ولی نوشتید **«sghl»**.

**راه‌حل Langwich:**
1. متن اشتباه را انتخاب کنید (مثلاً `sghl`)
2. F10 را بفشارید
3. متن خودکار به **«سلام»** تبدیل می‌شود!

**نگاشت کیبورد استفاده‌شده:** چیدمان استاندارد Microsoft Persian (مثل ویندوز ایران)

## 🛠 پیش‌نیازها

برای **ساخت** برنامه به دو چیز نیاز دارید:

### ۱. Visual Studio Community 2022 (رایگان)

1. به آدرس [visualstudio.microsoft.com](https://visualstudio.microsoft.com/downloads/) بروید
2. **Community** را دانلود و نصب کنید
3. در طول نصب، تیک **«.NET desktop development»** را بزنید

> 💡 اگر Visual Studio قبلاً نصب است ولی workload ندارد:
> Visual Studio Installer را باز کنید ← Modify ← تیک «.NET desktop development» ← Modify

### ۲. .NET 10 SDK

1. به [dotnet.microsoft.com/download/dotnet/10.0](https://dotnet.microsoft.com/download/dotnet/10.0) بروید
2. آخرین نسخه‌ی **SDK** (نه Runtime) را برای **Windows x64** دانلود و نصب کنید
3. برای تأیید نصب، **Command Prompt** را باز کنید و بنویسید:
   ```
   dotnet --version
   ```
   باید عدد `10.x.x` نمایش داده شود.

## 🚀 ساخت برنامه (صفر تا اجرا)

### قدم ۱: پوشه‌ی پروژه را آماده کنید

فایل zip دریافتی را در یک پوشه extract کنید. مثلاً:
```
C:\Projects\Langwich\
```

### قدم ۲: فایل Solution را باز کنید

در پوشه‌ی extract‌شده، روی **`Langwich.sln`** دوبار کلیک کنید.
Visual Studio باز می‌شود.

### قدم ۳: NuGet ها را بازیابی کنید

از منو: **Build ← Restore NuGet Packages**

(Langwich هیچ NuGet خارجی ندارد، ولی این قدم برای اطمینان انجام دهید.)

### قدم ۴: ساخت (Build)

کلیدهای **Ctrl + Shift + B** را بفشارید.

در پنجره‌ی **Output** باید پیامی شبیه این ببینید:
```
Build succeeded.
    0 Error(s)
    0 Warning(s)
```

### قدم ۵: اجرا

کلید **F5** را بفشارید (یا منو: **Debug ← Start Debugging**).

> ✅ اگر همه چیز درست باشد، **هیچ پنجره‌ای باز نمی‌شود** — این طبیعی است!
> Langwich در پس‌زمینه اجرا می‌شود. آیکون آن را در سینی سیستم (کنار ساعت ویندوز) پیدا کنید.

## 📦 ساخت یک فایل exe تکی برای توزیع

این دستور یک فایل `Langwich.exe` واحد می‌سازد که روی هر ویندوزی اجرا می‌شود:

### روش ۱: از طریق Command Prompt (توصیه‌شده)

1. **Command Prompt** را باز کنید
2. به پوشه‌ی پروژه بروید:
   ```cmd
   cd C:\Projects\Langwich\Langwich
   ```
3. دستور publish را اجرا کنید:
   ```cmd
   dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o ./publish
   ```
4. فایل نهایی اینجاست:
   ```
   C:\Projects\Langwich\Langwich\publish\Langwich.exe
   ```

### روش ۲: از طریق Visual Studio

1. در Solution Explorer روی **Langwich** پروژه راست‌کلیک کنید
2. **Publish** را انتخاب کنید
3. **Folder** → **Next** → **Finish**
4. در صفحه‌ی Publish روی **Show all settings** کلیک کنید و تنظیمات را بزنید:
   - Configuration: Release
   - Target Runtime: win-x64
   - Self-contained: ✅
   - Single file: ✅
5. روی **Publish** کلیک کنید

## 📖 نحوه‌ی استفاده

### روز اول

1. `Langwich.exe` را اجرا کنید
2. آیکون 🟣 در سینی سیستم (کنار ساعت) ظاهر می‌شود

### استفاده روزانه

| مرحله | کار |
|---|---|
| ۱ | متن اشتباه را در هر برنامه‌ای انتخاب کنید |
| ۲ | F10 را بفشارید |
| ۳ | متن خودکار تبدیل می‌شود! |

### مثال‌ها

| متن اشتباه | بعد از F10 |
|---|---|
| `sghl` | `سلام` |
| `]d;i hvldk` | `چی خبر دارین` |
| `سلام` | `sghl` |
| `به` | `fi` |

### منوی سینی

روی آیکون Langwich **راست‌کلیک** کنید:
- **⚙ تنظیمات** — پنجره‌ی تنظیمات
- **✕ خروج** — بستن برنامه

## ⚙ تنظیمات

با کلیک روی **تنظیمات** در منوی سینی می‌توانید:

- **میانبر سراسری** را تغییر دهید (پیش‌فرض: F10)
  - روی دکمه‌ی میانبر کلیک کنید
  - کلید مورد نظر را بفشارید (مثلاً Ctrl+F10 یا F8)
- **اجرای خودکار با ویندوز** را فعال/غیرفعال کنید
- **اعلان** بعد از تبدیل را فعال/غیرفعال کنید
- بین **تم تاریک** و **تم روشن** جابه‌جا شوید
- روی **ذخیره** کلیک کنید

## 🔧 مشکلات رایج

### ❓ «Build succeeded» نمی‌گیرم

**راه‌حل:**
1. مطمئن شوید .NET 10 SDK نصب است (`dotnet --version` در CMD)
2. Visual Studio را ببندید و دوباره باز کنید
3. **Build ← Clean Solution** سپس دوباره Ctrl+Shift+B

---

### ❓ آیکون در سینی نیست

در بعضی ویندوزها آیکون‌های سینی مخفی می‌شوند:
1. روی فلش ▲ کنار ساعت کلیک کنید
2. Langwich را پیدا کنید

---

### ❓ F10 کار نمی‌کند

**دلیل ۱:** میانبر توسط برنامه‌ی دیگری گرفته شده.
→ از تنظیمات یک کلید دیگر انتخاب کنید (مثلاً Ctrl+F10).

**دلیل ۲:** برنامه‌ی هدف با دسترسی Administrator اجرا شده.
→ Langwich.exe را هم **به‌صورت Administrator** اجرا کنید:
راست‌کلیک روی Langwich.exe ← **Run as administrator**

---

### ❓ SmartScreen هشدار می‌دهد

این طبیعی است — برای exe های امضا نشده (unsigned) رخ می‌دهد.

1. روی **«More info»** کلیک کنید
2. روی **«Run anyway»** کلیک کنید

---

### ❓ آنتی‌ویروس هشدار می‌دهد

بعضی آنتی‌ویروس‌ها برنامه‌هایی که کلیدهای سراسری ثبت می‌کنند را مشکوک می‌دانند.
این یک **false positive** است. Langwich کد مخربی ندارد — سورس آن جلوی شما است!

اگر مشکل داشتید، Langwich را به **Exceptions** آنتی‌ویروس اضافه کنید.

## ⚠ محدودیت‌های شناخته‌شده

- **بازی‌های تمام‌صفحه:** بیشتر بازی‌ها از کلیپ‌بورد استاندارد استفاده نمی‌کنند؛ تبدیل کار نخواهد کرد.
- **برنامه‌های Administrator:** اگر برنامه‌ی هدف با دسترسی Admin اجرا شده، Langwich هم باید Admin باشد.
- **ردیف اعداد و شیفت:** نگاشت اعداد (`۱`→`1`) و کاراکترهای Shift فعلاً پیاده‌سازی نشده‌اند.
